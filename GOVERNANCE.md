# Governance

Bursar is maintained by its core team, who review and merge changes, triage issues, handle
security reports and enforce the [Code of Conduct](CODE_OF_CONDUCT.md) across every bursar-world
repository.

Changes to the contracts deployed on Robinhood Chain are made on chain, through a timelock, and
a merged pull request never changes them by itself. How that works, how protocol parameters
change and how maintainers are added is set out in the
[bursar repository's GOVERNANCE.md](https://github.com/bursar-world/bursar/blob/main/GOVERNANCE.md),
which is the governing document for the project.
