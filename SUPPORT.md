# Getting help

## Using Bursar

The [documentation](https://app.bursar.world/docs) covers creating and funding a mandate, setting
limits, paying from an agent and taking on work as a provider. Product information is at
[bursar.world](https://bursar.world).

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/bursar-world/bursar/discussions) on the bursar
repository. Search first, since someone may have asked already. Say what you are trying to do,
which commit or package you are using, and paste the full error. Leave out keys, passwords and API
tokens.

## Bugs and feature requests

Open an issue on the repository concerned, using one of its forms.

## Anything else

Email [hello@bursar.world](mailto:hello@bursar.world). News and release notes are posted on X at
[@UseBursar](https://x.com/UseBursar).

## Security

Never report a vulnerability in public. Follow [SECURITY.md](SECURITY.md).

## Response times

Maintainers answer discussions and issues as time allows. There is no paid support and no
committed response time outside the security process.
